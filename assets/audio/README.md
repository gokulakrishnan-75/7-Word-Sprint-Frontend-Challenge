# Cinematic Audio Tracks

You can place optional MP3 soundtrack files in this directory:

- `ambience.mp3` — Ancient atmospheric soundtrack / mystic drone
- `battle.mp3` — War drums & battle clash soundtrack
- `decision.mp3` — War room suspense & decision atmosphere
- `victory.mp3` — Triumphant resolution & sacred temple bells

### Procedural Synthesizer Fallback
The website includes a built-in Web Audio API sound synthesizer that generates realistic harmonic drones, war drums, temple gongs, and gold coin chimes directly in code. If these MP3 files are not present, the procedural sound synthesizer automatically provides the complete audio experience with zero latency.
